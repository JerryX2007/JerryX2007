## `> featured build`

### [Is It Down? →](https://isitdown-ivory.vercel.app/)

A production-deployed website availability checker that performs fresh server-side checks, displays response details, and combines them with anonymous community outage reports.

| Product | Engineering |
| --- | --- |
| Fresh HTTP and HTTPS availability checks | React and TypeScript frontend with a FastAPI backend |
| Response time, status code, and shareable result pages | PostgreSQL production database with SQLAlchemy and Alembic |
| Anonymous community outage reporting | Input normalization and private-address rejection |
| 24-hour and 7-day outage history | Hashed reporter identifiers and duplicate-report protection |
| Responsive desktop and mobile interface | Structured JSON logging, request IDs, and Sentry monitoring |
| [Live application](https://isitdown-ivory.vercel.app/) | [Source code and documentation](https://github.com/JerryX2007/isitdown) |

**Currently building next:** scheduled recurring checks with a background worker and automated incident detection.
